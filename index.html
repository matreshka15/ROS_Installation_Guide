💻 系统要求

支持的操作系统

ROS 版本 Ubuntu 版本 类型 状态
Noetic Ninjemys Ubuntu 20.04 LTS ROS 1 ✅ 推荐
Melodic Morenia Ubuntu 18.04 LTS ROS 1 ✅ 支持

硬件要求

  • 处理器：64 位处理器（Intel/AMD x86_64 或 ARM64）
  • 内存：至少 4GB RAM（推荐 8GB 以上）
  • 存储空间：至少 10GB 可用空间
  • 网络：稳定的互联网连接（用于下载软件包）
💡 提示：如果您是国内用户，建议使用镜像源（清华、阿里等）以获得更快的下载速度。

🎯 版本选择

🔍 ROS 1 vs ROS 2 对比

特性 ROS 1 ROS 2
架构设计 基于主从架构，单点故障风险 分布式架构，无单点故障
通信机制 基于 TCPROS/UDPROS，不保证可靠性 基于 DDS，支持多种 QoS 策略
多机通信 需要配置网络，复杂度较高 原生支持，配置简单
实时性支持 有限支持，依赖外部实时内核 原生支持实时操作
安全特性 基本没有 内置安全机制（身份验证、加密）
生态系统 成熟，大量现有包和工具 快速发展，持续完善
学习曲线 相对平缓 更陡峭，需要了解 DDS 概念
💡 选择建议：
  • 如果您是新手，推荐从 ROS 1 Noetic 开始学习
  • 如果您正在开发新项目，推荐使用 ROS 2 Iron 或 ROS 2 Humble
  • 如果您需要兼容现有 ROS 1 代码，推荐使用 ROS 1 Noetic

📦 ROS Noetic Ninjemys 安装指南

适用系统：Ubuntu 20.04 LTS | 类型：ROS 1 最新版

🔧 第 1 步：更新系统

sudo apt update
sudo apt upgrade -y

🔧 第 2 步：添加 ROS 源和密钥

方案 A：使用官方源（网络良好时）

sudo sh -c 'echo "deb http://packages.ros.org/ros/ubuntu $(lsb_release -sc) main" > /etc/apt/sources.list.d/ros-latest.list'
sudo apt-key adv --keyserver 'hkp://keyserver.ubuntu.com:80' --recv-key C1CF6E31E6BADE8868B172B4F42ED6FBAB17C654

方案 B：使用清华镜像源（国内推荐）⭐

sudo sh -c '. /etc/lsb-release && echo "deb http://mirrors.tuna.tsinghua.edu.cn/ros/ubuntu/ `lsb_release -cs` main" > /etc/apt/sources.list.d/ros-latest.list'
sudo apt-key adv --keyserver 'hkp://keyserver.ubuntu.com:80' --recv-key C1CF6E31E6BADE8868B172B4F42ED6FBAB17C654

🔧 第 3 步：安装 ROS

完整版（推荐）：包含 ROS、rqt、rviz 等全部工具

sudo apt update
sudo apt install ros-noetic-desktop-full

桌面版：基础功能 + 可视化工具

sudo apt install ros-noetic-desktop

基础版：仅核心功能（用于嵌入式）

sudo apt install ros-noetic-ros-base

🔧 第 4 步：设置环境

方式 1：临时设置（仅当前终端）

source /opt/ros/noetic/setup.bash

方式 2：永久设置（推荐）

echo "source /opt/ros/noetic/setup.bash" >> ~/.bashrc
source ~/.bashrc

🔧 第 5 步：安装依赖工具

sudo apt install python3-rosdep python3-rosinstall python3-rosinstall-generator python3-wstool build-essential

🔧 第 6 步：初始化 rosdep

国内用户推荐：使用 rosdepc

sudo apt install python3-pip
sudo pip3 install rosdepc
sudo rosdepc init
rosdepc update

或使用标准 rosdep：

sudo rosdep init
rosdep update
✅ 完成！ 恭喜您已成功安装 ROS Noetic。请重新打开终端或执行 source ~/.bashrc 后开始使用。

📦 ROS Melodic Morenia 安装指南

sudo sh -c 'echo "deb http://mirrors.tuna.tsinghua.edu.cn/ros/ubuntu bionic main" > /etc/apt/sources.list.d/ros-latest.list'

# 安装

📦 ROS 2 Iron Irwini 安装指南

适用系统：Ubuntu 22.04 LTS | 类型：ROS 2 现代版

🔧 第 1 步：系统准备

打开 "软件和更新" 设置，确保以下选项被勾选：

  • main
  • universe
  • restricted
  • multiverse

🔧 第 2 步：备份并更新软件源列表

# 备份原始软件源
sudo cp /etc/apt/sources.list /etc/apt/sources.list.backup

# 更新软件包索引
sudo apt update
sudo apt upgrade -y

🔧 第 3 步：添加 ROS 2 软件源

方案 A：有 VPN/良好网络连接

sudo apt install curl gnupg2 lsb-release
sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key -o /usr/share/keyrings/ros-archive-keyring.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] http://packages.ros.org/ros2/ubuntu $(source /etc/os-release && echo $UBUNTU_CODENAME) main" | sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null

方案 B：无 VPN/网络连接受限

# 使用清华大学源
sudo apt install curl gnupg2 lsb-release
sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key -o /usr/share/keyrings/ros-archive-keyring.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] http://mirrors.tuna.tsinghua.edu.cn/ros2/ubuntu $(source /etc/os-release && echo $UBUNTU_CODENAME) main" | sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null

🔧 第 4 步：更新软件包索引

sudo apt update

🔧 第 5 步：安装 ROS 2

完整版（推荐） - 包含 ROS 2、rqt、rviz、机器人通用库、2D/3D 模拟器等

sudo apt install ros-iron-desktop-full

桌面版 - 包含 ROS 2 基础功能、机器人通用函数库、rqt 工具箱和 rviz 可视化工具

sudo apt install ros-iron-desktop

基础版 - 仅包含核心功能包、构建工具和通信机制，适合嵌入式系统

sudo apt install ros-iron-ros-base

🔧 第 6 步：设置环境变量

方式 1：临时设置（当前终端有效）

source /opt/ros/iron/setup.bash

方式 2：永久设置（推荐）

# Bash 用户
echo "source /opt/ros/iron/setup.bash" >> ~/.bashrc
source ~/.bashrc

# Zsh 用户
echo "source /opt/ros/iron/setup.zsh" >> ~/.zshrc
source ~/.zshrc

🔧 第 7 步：安装开发工具

sudo apt install python3-colcon-common-extensions python3-rosdep python3-vcstool build-essential

🔧 第 8 步：初始化 rosdep

方案 A：有 VPN/良好网络连接

sudo rosdep init
rosdep update

方案 B：无 VPN/网络连接受限（推荐国内用户）

# 安装pip3
sudo apt install python3-pip

# 安装rosdepc
sudo pip3 install rosdepc

# 初始化rosdepc
sudo rosdepc init
rosdepc update
✅ 完成！ 恭喜您已成功安装 ROS 2 Iron。请重新打开终端或执行 source ~/.bashrc 后开始使用。

❓ 常见问题

Q1: 下载速度慢

A: 建议使用国内镜像源：
  • 清华大学：mirrors.tuna.tsinghua.edu.cn
  • 阿里云：mirrors.aliyun.com
  • 中科大：mirrors.ustc.edu.cn

Q2: 密钥添加失败

A: 使用以下替代方法： 
curl -s https://raw.githubusercontent.com/ros/rosdistro/master/ros.asc | sudo apt-key add -

Q3: rosdep update 失败

A: 国内用户推荐使用 rosdepc： 
sudo pip3 install rosdepc
sudo rosdepc init
rosdepc update

Q4: 找不到 ROS 命令

A: 确保已设置环境变量： 
source /opt/ros/DISTRO/setup.bash  # 替换 DISTRO 为您的 ROS 版本，如 noetic 或 iron
# 或永久添加到 ~/.bashrc 中
echo "source /opt/ros/DISTRO/setup.bash" >> ~/.bashrc
source ~/.bashrc

Q5: 如何卸载 ROS

A: 运行以下命令： 
# ROS 1
sudo apt remove ros-noetic-*  # 替换 noetic 为您的 ROS 版本
sudo apt autoremove

# ROS 2
sudo apt remove ros-iron-*  # 替换 iron 为您的 ROS 版本
sudo apt autoremove

Q6: ROS 2 环境变量冲突

A: 确保只加载了一个 ROS 版本的环境变量：
  • 检查 ~/.bashrc 或 ~/.zshrc 文件，确保只添加了一个 ROS 版本的环境变量
  • 如果需要切换 ROS 版本，可以手动加载对应版本的环境变量

Q7: 编译功能包时出现依赖错误

A: 尝试以下解决方案： 
# ROS 1
sudo apt install python3-rosdep
sudo rosdep init
rosdep update
rosdep install --from-paths src --ignore-src -r -y

# ROS 2
sudo apt install python3-colcon-common-extensions
sudo rosdep init
rosdep update
rosdep install --from-paths src --ignore-src -r -y

Q8: roscore 启动失败（ROS 1）

A: 尝试以下解决方案：
  • 检查是否已经有 roscore 在运行：ps aux | grep roscore
  • 删除旧的日志文件：rm -rf ~/.ros/log
  • 检查环境变量设置是否正确

Q9: 小海龟节点无法启动

A: 尝试以下解决方案： 
# ROS 1
sudo apt install ros-noetic-turtlesim  # 替换 noetic 为您的 ROS 版本

# ROS 2
sudo apt install ros-iron-turtlesim  # 替换 iron 为您的 ROS 版本

Q10: RViz 无法正常显示

A: 尝试以下解决方案：
  • 确保显卡驱动已正确安装
  • ROS 1 使用 rviz 命令，ROS 2 使用 rviz2 命令
  • 检查是否缺少相关依赖包

Q11: ROS 2 节点通信问题

A: 尝试以下解决方案：
  • 检查 DDS 配置是否正确
  • 确保所有节点使用相同的 ROS_DOMAIN_ID
  • 使用 ros2 topic list 命令检查话题是否正常发布
  • 使用 ros2 node list 命令检查节点是否正常运行

Python 发布者节点

#!/usr/bin/env python3
import rospy
from std_msgs.msg import String

rospy.init_node('talker')
pub = rospy.Publisher('chatter', String, queue_size=10)
rate = rospy.Rate(10)

while not rospy.is_shutdown():
    msg = "Hello ROS %s" % rospy.get_time()
    pub.publish(msg)
    rospy.loginfo(msg)
    rate.sleep()

Python 订阅者节点

#!/usr/bin/env python3
import rospy
from std_msgs.msg import String

def callback(data):
    rospy.loginfo("I heard: %s", data.data)

rospy.init_node('listener')
rospy.Subscriber('chatter', String, callback)
rospy.spin()
